- V1.4.10에서는 모든 필지의 최종면적을 0.01㎡ 단위로 배분합니다. 정수 필지의 최종 보정면적에 소수점이 생길 수 있습니다.
- **필지별 최종 보정면적 합계 = 원본 편입면적**을 Decimal 정수단위로 검증합니다.
- 대장면적과 편입면적은 원본 숫자 값을 절사하지 않습니다. 대장면적 초과 등 기존 보정 보류 조건은 유지합니다.
- 엑셀에는 불필요한 소수점 0을 표시하지 않습니다. 예: `1000`, `1000.3`, `1000.35`.
- 편입면적에 0.001㎡ 이하 자릿수가 남아 있는 경우 0.01㎡로 몰래 반올림하지 않고 보류 목록에 원인을 표시합니다.
- **용도지역 경계의 누락·중복 가능성**은 기존과 같이 보정 후 공간검토필요 목록에 표시합니다. 보정 결과의 법적 확정은 별도 검증이 필요합니다.

### V1.4.9 사용자 업데이트

프로그램 종료(`Ctrl+C`) → `app.py`, `zone_adjust.py` 교체 → 기존 실행용 `.bat`로 재시작. `.venv`와 나머지 프로그램 파일은 유지합니다.
기존 분석 결과는 다시 실행해서 받아 주세요.


## V1.4.11 — 필지별 원본 편입면적 정밀도 유지 (2026.10.19)

- V1.4.10의 전 필지 0.01㎡ 배분 방식을 수정했습니다.
- PNU별 편입면적이 정수이면 최종면적도 1㎡ 정수, 한 자리 소수이면 0.1㎡, 두 자리 소수이면 0.01㎡ 단위로 배분합니다.
- 1,000.0 또는 1,000.00으로 저장돼도 수치가 정수이면 1㎡ 단위를 선택합니다.
- 보정한 용도지역 면적 합계는 PNU별 원본 편입면적과 일치해야 합니다.
- 원본의 편입면적/대장면적은 변경하지 않습니다. SHP의 FINAL_M2는 수치 필드이므로 QGIS에서 고정 소수점 형태로 보일 수 있지만 계산 결과 자체는 해당 단위의 배수입니다.
- 필지별 검증/보정상세에서 적용보정단위_m2를 확인할 수 있습니다.

## V1.4.14 : 2-3 훼손 제외면적 검증

2-2에서 용도지역별 면적을 보정한 뒤 2-3에서 검증용 제외 후보와 잔여 도형을 구분할 수 있습니다.
수기 매뉴얼의 지목/용도지역 조건은 **검증용 가정**으로 제공됩니다. 조건을 수정한 뒤 실행하세요.

- 산출: 훼손 제외 후보 검증 Excel, 훼손제외_대상.shp ZIP, 제외후_잔여.shp ZIP
- 기본 제외 지목 후보: `대, 장, 학, 도, 철, 체, 원`
- 기본 조건부 보존 지목: `전, 답, 임, 염, 천, 유, 공` (주거/상업/공업/계획관리 지역)
- 건축물 O는 기본값에서 '건축물 검토 필요' 상태로 남으며, 명시적으로 체크한 경우에만 전체 구간 제외 후보가 됩니다.
- 필지별 `제외 후보 면적+잔여 면적=편입면적` 검증을 통과하지 못하면 결과를 저장하지 않습니다.
- 2-2 원본 구적면적 대신 보정한 최종보정면적을 사용합니다. SHP 도형 크기와 속성표 면적 차이가 있을 수 있습니다.
- 보정 실패 및 최종 0㎡ 구간은 제외/잔여 SHP에 넣지 않고 Excel 검증 시트에 기록합니다.

본 도구가 생성한 제외 후보는 법정 훼손 제외면적의 확정 판정이 아닙니다.
